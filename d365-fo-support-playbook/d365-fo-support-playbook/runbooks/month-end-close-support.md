# Runbook: Month-End Close Support Checklist

Coordinate with Finance; the support analyst keeps the system side moving.

**Before close**
- [ ] Confirm batch jobs scheduled for the period are healthy
- [ ] Check pending workflows (journals, invoices, expense reports) and chase stuck approvals
- [ ] Confirm imports (bank, journals, intercompany) are complete

**During close**
- [ ] Subledger transactions posted (AP, AR, inventory, fixed assets)
- [ ] Fixed asset depreciation proposals posted
- [ ] Foreign currency revaluation run where applicable
- [ ] Intercompany balances reviewed across entities
- [ ] Accruals and allocations posted

**After close**
- [ ] Ledger calendar period set per Finance instruction (on hold / closed)
- [ ] Log issues and root causes for the retrospective

**Common incidents:** transaction blocked because the period is already closed; revaluation run after period lock; batch failure at deadline; intercompany out of balance.
